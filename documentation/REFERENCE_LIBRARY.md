# DMF Reference Library — Design / Motion / Craft

Research phase (Agent B). Best-in-class references studied for **inspiration, not imitation**.
Positioning to serve: **"Engineering the roots of development"** — the systems beneath successful development.

How to read each record:
- **Works** = what's strong · **Why** = the underlying principle · **Adapt** = translate to DMF · **Don't copy** = trap to avoid

---

## Engineering / Infrastructure Firms

### 1. Arup — arup.com
- **Works:** Editorial, journal-like homepage. Long-form "perspectives" and project stories treated as thought-leadership, not brochure pages. Restrained palette (near-black, off-white, one accent), generous whitespace, large serif/sans pairing for headlines.
- **Why:** Positions engineering as *intellect* — the firm sells thinking, not deliverables. Content-first hierarchy makes a technical firm feel authoritative and human.
- **Adapt:** Treat DMF projects as *stories about systems* ("what problem beneath the development did we solve"). Editorial rhythm; a single disciplined accent color.
- **Don't copy:** Their sprawling content volume — DMF is smaller; a bloated newsroom would look thin. Keep it curated.

### 2. AECOM — aecom.com
- **Works:** Bold full-bleed hero imagery with big confident statements; sector-led navigation (Transportation, Water, Buildings...). Strong data/impact callouts ("$X delivered", scale numbers).
- **Why:** Global-scale credibility signalled through imagery scale + quantified impact. Sector nav lets diverse audiences self-select fast.
- **Adapt:** Sector/discipline-led primary nav (Master Planning, Roads & Infrastructure, Traffic, Civil, Structural, Architecture, Landscape). Use quantified proof points (km of road, hectares master-planned).
- **Don't copy:** Corporate-stock hero energy and generic optimism copy — reads faceless. DMF should feel grounded and specific.

### 3. WSP — wsp.com
- **Works:** Clean sector grids, clear service taxonomy, muted palette with a single brand red. Project cards with consistent metadata (location, sector, service).
- **Why:** Extreme consistency in card metadata makes a huge portfolio scannable and trustworthy — the *system* is the design.
- **Adapt:** Rigid, consistent project-card schema (Name · Location · Discipline · Role · Year). Consistency > variety.
- **Don't copy:** Overall flatness/blandness — competent but unmemorable. DMF needs more craft and motion personality.

### 4. AtkinsRéalis — atkinsrealis.com
- **Works:** Post-rebrand confidence; strong typographic lockups, dark-mode-leaning sections, purposeful use of a vivid accent. Sustainability/net-zero framing woven through.
- **Why:** A single, strongly-owned accent against neutral ground creates instant brand recall without gaudiness.
- **Adapt:** Commit to ONE ownable accent (earth/root tone or a technical cyan) used sparingly for emphasis, links, line-draw highlights.
- **Don't copy:** Heavy corporate ESG boilerplate. Keep DMF's message about the *substrate of development*, concrete not slogan.

### 5. Jacobs — jacobs.com
- **Works:** "Challenging today, reinventing tomorrow" — tight verbal identity carried consistently. Human-centred imagery, clear outcomes framing.
- **Why:** A memorable, repeated tagline structure gives an engineering firm a *voice*. Outcome-led copy ("we did X so Y happened").
- **Adapt:** Lock a short verbal system around "roots / foundations / systems beneath." Frame every case study as outcome-led.
- **Don't copy:** Their scale of glossiness; DMF should feel like craftsmen, not a conglomerate.

### 6. Mott MacDonald — mottmac.com
- **Works:** Insight-driven, understated. Strong on structured project detail pages: challenge → approach → outcome, with technical specifics. Reserved palette.
- **Why:** The challenge/approach/outcome spine is the gold-standard case-study skeleton — legible to both clients and peers.
- **Adapt:** Adopt this three-act case-study template verbatim in structure (not styling). Include hard technical specifics — it signals real engineering.
- **Don't copy:** The visual reserve/greyness — DMF can be warmer and more crafted.

### 7. Ramboll — ramboll.com
- **Works:** Nordic clarity — lots of air, calm typography, sustainability-forward, soft imagery. Human + environmental tone.
- **Why:** Whitespace and calm signal confidence and long-termism (fitting "roots"). Restraint reads as premium.
- **Adapt:** Generous spacing, unhurried pacing, nature/ground-connected imagery language that supports the "roots" metaphor.
- **Don't copy:** The softness can read as low-energy; DMF needs a firmer structural/technical edge alongside the calm.

## Architecture / Urbanism

### 8. BIG — big.dk
- **Works:** Portfolio-first. Dense project grid, imagery does all the talking, near-zero chrome. Program-type taxonomy (Culture, Work, Infrastructure, Space...). Monochrome UI, color only from photography.
- **Why:** Total confidence in the work — the design gets out of the way. Category icons + location metadata make a massive catalogue browsable.
- **Adapt:** Let project imagery carry color; keep UI monochrome. Program/discipline taxonomy with consistent iconography and location tags.
- **Don't copy:** BIG's near-absent narrative — they can rely on fame; DMF must *explain the system beneath* each project, so pair imagery with concise story.

### 9. Foster + Partners — fosterandpartners.com
- **Works:** Serene, precise, black-on-white. Projects, Expertise, Studio split. Slow, elegant image transitions; typographic restraint bordering on austere.
- **Why:** Precision *is* the brand message — the whitespace and quiet motion mirror engineering exactness.
- **Adapt:** Precision as an aesthetic — tight grid, exact alignment, quiet transitions. "Expertise" as a first-class nav peer to "Projects."
- **Don't copy:** The austerity/coldness. DMF's "roots" story wants a touch more warmth and human ground.

### 10. SOM — som.com
- **Works:** Numbered section system ("01/ Our Purpose"), modular card grid mixing Projects/Stories/News, EN/中文 toggle, monochrome + grayscale imagery, progressive vertical disclosure.
- **Why:** The `01/ 02/` numbering imposes a technical, documentary rhythm — feels like reading a set of drawings/specs. Mixed content types keep the firm feeling active.
- **Adapt:** Borrow the **numbered-section device** — it maps beautifully onto engineering/CAD language (sheet numbers, phases). Use for homepage and case-study chapters.
- **Don't copy:** The grayscale-everything look; DMF can allow selective, controlled color.

### 11. UNStudio — unstudio.com
- **Works:** More expressive/experimental motion, knowledge-network framing ("UNSense"), diagrammatic thinking made visible, playful but controlled interactions.
- **Why:** Shows how a technical practice can be *diagrammatic and systems-thinking-forward* on screen without losing rigor.
- **Adapt:** Make DMF's systems-thinking visible via diagrammatic reveals (network/relationship diagrams of how infrastructure layers connect).
- **Don't copy:** The experimental flourish for its own sake — DMF's motion must always encode meaning, never decoration.

## Award-Tier Digital Experience (motion / scroll / type craft)

### 12. By-Kin — by-kin.com  *(Awwwards SOTD + Developer Award, FWA, CSS Design Awards)*
- **Works:** Masterclass in restraint. Confident editorial typography, *weighted* smooth-scroll, transitions so clean the whole site feels like one continuous surface. Next.js + GSAP. Won a **Developer Award** — motion holds up frame-by-frame.
- **Why:** Craft is felt, not announced. Smooth-scroll with real inertia + flawless page transitions = perceived quality that maps directly to "we engineer things precisely."
- **Adapt:** Invest in *engineered* smooth scroll and seamless route transitions. This is the single best analogue for "engineering craft = digital craft." Editorial type as primary UI.
- **Don't copy:** Nothing to avoid stylistically — but don't ship it half-built; janky smooth-scroll is worse than none. It must be truly performant.

### 13. Obys Agency — obys.agency
- **Works:** Kinetic typography as the core visual system — letters scale, split, morph on scroll. Type behaves like motion design. Grid overlays, mono/technical labels, coordinate-style micro-text.
- **Why:** Type-as-hero gives a distinct, ownable identity with almost no imagery cost — and technical micro-labels read as "measured / engineered."
- **Adapt:** A **kinetic headline system** for key statements (hero, section intros) + **technical micro-typography** (coordinates, sheet refs, units, grid ticks) as connective tissue — this is DMF's route to the CAD/technical visual language.
- **Don't copy:** Full-throttle kinetic type everywhere — exhausting and hurts legibility. Reserve motion for a few hero moments; keep body calm.

### 14. OFF+BRAND F1 driver site — *(Awwwards Site of the Year 2025)*
- **Works:** Cinematic scroll sequences, a rotating 3D object that tracks reading position, single vivid accent (lime) against dark, sound/scene choreography.
- **Why:** Scroll drives a *narrative*, not just reveals — the reader is walked through a story with a hero object anchoring attention.
- **Adapt:** A scroll-choreographed hero for ONE flagship moment — e.g. a rotating/sectioning 3D infrastructure element (road cross-section, drainage layer, master-plan massing) that "builds" as you scroll = literal "roots beneath development."
- **Don't copy:** Heavy WebGL + audio across the whole site — kills performance/accessibility and overwhelms a B2B consultancy audience. One hero set-piece, max.

## CAD / Technical Visual-Language Cues (synthesized)

Recurring devices worth stealing *in spirit* for DMF's "engineering the roots" theme:
- **Line-drawing reveals:** SVG stroke-dashoffset animations that "draw" plans, sections, alignments as they enter view (blueprint coming to life).
- **Grid & coordinate scaffolding:** faint construction grid, tick marks, coordinate/station micro-labels — signals surveyed precision (Obys, SOM's `01/`).
- **Sectional / layered reveals:** show the *substrate* — peel back surface to expose infrastructure layers beneath (directly serves the "roots" metaphor).
- **Monochrome UI + selective accent:** color discipline across every reference; imagery/diagrams carry chroma, UI stays neutral + one accent.
- **Consistent project metadata schema:** Name · Location · Discipline · Role · Year — enforced everywhere (WSP, BIG, Mott MacDonald).

## Top 5 Moves DMF Should Steal (in spirit)

1. **Engineered smooth-scroll + seamless transitions (By-Kin).** Make digital craft *be* the proof of engineering craft. Non-negotiable that it's performant, not decorative.
2. **The "roots" set-piece: a scroll-built sectional 3D/2D reveal (OFF+BRAND + line-drawing).** One flagship hero where infrastructure layers assemble beneath a development as you scroll — the positioning made literal, once, well.
3. **Numbered, documentary section system `01/ 02/` (SOM) + technical micro-typography (Obys).** Give the whole site the rhythm of a drawing set: sheet numbers, coordinates, units, grid ticks.
4. **Challenge → Approach → Outcome case-study spine with hard technical specifics (Mott MacDonald + Arup editorial voice).** Every project explains the *system beneath the development*, outcome-led, with real numbers.
5. **Ruthless color restraint: monochrome UI + one ownable accent; imagery carries color (BIG / Foster / AtkinsRéalis).** Discipline reads as precision and premium — and lets the "roots"/ground palette own the brand.
